# Java & DSA Practice

A collection of **27 Java practice programs** focused on problem solving, implementation techniques, and introductory DSA concepts.

## Key Technical Concepts

* **Two Pointers** — array reversal and in-place rotation
* **Frequency Counting** — arrays vs HashMap
* **In-Place Algorithms** — reducing auxiliary space
* **Recursion vs Iteration** — factorial implementation
* **Array Traversal** — max/min, second largest, zero movement
* **String Processing** — `charAt()`, `indexOf()`, `StringBuilder`
* **Java Collections** — `ArrayList`, `HashMap`, `Collections`
* **Algorithm Comparison** — iterative vs mathematical, manual vs library-based approaches
* **Time & Space Complexity** — comparing different implementations rather than only checking correctness
